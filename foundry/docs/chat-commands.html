Most handling of the map is through /astro chat commands. The command itself is not posted and the reply is whispered by default.

Searches that match several worlds offer up to twelve buttons. The button centers the map, plots the route, or creates the actor, depending on the command that asked.

/astro help

Whisper this list of commands.

/astro find <world>

Search by name. The name needs at least two characters. Each button centers the map on that world.

/astro route j=[1-6] <world>

Plot a jump route from the current world to the named world. Omit j= to use the jump range from settings. The range, when given, is a whole number from 1 through 6. The route starts at the world the map is on, or at the home world when the map has not chosen one. An exact name match is used when several worlds match. Each button centers the map on that stop.

/astro borders

Show or hide political borders on the chart.

/astro ships

Show or hide Blueprint Ship marks on the chart. This command is present when Koko's Traveller Ship Design is active. With that module turned off, the command is omitted from /astro help, and typing it whispers that the ship design module is not active.

/astro gm snap

GM only. Center every other player on the world your map is centered on.

/astro gm filters

GM only. Give every other player your tech level, starport, and trade-code filters.

/astro actor <world>

Create a world actor in the worlds compendium, grouped by sector and subsector. Omit the name to use the currently selected world, or the world the map is centered on when nothing is selected. If a World actor already exist for the world, it hex is left in place. The name, when given, needs at least two characters.

/astro filter

Whisper current setting for the tech level, starport, and trade-code filters.

/astro filter clear

Turn off tech, starport, and trade-code highlighting.

/astro filter TL=[0-F]

Highlight worlds at that tech level or higher. The digit runs from 0 through F.

/astro filter SP=[A-E]

Highlight worlds with that starport or better. The letter runs from E through A.

/astro filter Trade=[trade codes]

Highlight worlds that have the named trade codes. Separate codes with commas. A code the map does not know rejects the whole command. A field you leave out stays as it is. Tech, starport, and trade can be set together:

/astro filter TL=A SP=C Trade=Ri,Ag

The trade codes are Ag, As, Ba, De, Fl, Ga, Hi, Ht, Ic, In, Lo, Lt, Na, Ni, Po, Ri, Va, Wa, Ab, An, Cp, Cs, Cx, Cy, Da, Di, Fa, Fo, He, Mi, Mr, Pa, Pe, Ph, Pi, Pr, Px, Pz, Re, Rs, and Sa.
