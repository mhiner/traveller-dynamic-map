Open Configure Settings and choose Koko's Traveller Astrogation. These values belong to the world. They apply to every player.

Default home system

The world the Astrogation scene opens on. The default is Regina. A blank value also uses Regina. When several worlds share the name, the Spinward Marches world is used. Once a user has opened the map, it will be retored to last viewed state.

Jump range

How many parsecs the ship can jump, from 1 through 6. The default is 2. Routes and the list of worlds within range use this number, unless a chat command names a different range. It is eventually intended to be replaced by Ship actors.

Minimum zoom

The smallest explore-map magnification. The default is 0.5(1:2 scale). A value of 1 is one chart pixel per screen pixel.

Maximum zoom

The largest explore-map magnification. The default is 3 (3:1 scale).

Dark view

Turn it on to draw using a black ground.

Selected hex

Off by default. Turn it on to outline the selected world’s hex in yellow.

Use sector compendium

On by default. Sectors saved in the Sector Data compendium are used when they are present. Sectors that are not packed still come from Traveller Map.

Compendium only

Off by default. Turn it on to stop calling Traveller Map. The map, find, and routes then stay inside the sectors saved in Sector Data. Leave it off and the map still prefers packed sectors, then asks Traveller Map for the rest.

Import sectors

A GM-only button. It asks for two corners of the sector grid. The box includes both corners. Borders and trade routes are saved with each sector. Sectors already in Sector Data is skipped.

The coordinates are the sector-grid numbers shown when Traveller Map is zoomed out. For example, (-5, 0) to (3, 2) covers the Spinward Marches and the sectors around it. (-8, -4) to (7, 3) covers most of Charted Space.
